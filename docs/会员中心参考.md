# 会员中心参考（参考 AI-Fortune + 新增采购/招聘发布）

## 一、参考 AIF 会员中心

现有会员中心包含（前端参考 ai-fortune.net 会员中心页，后端在 web-api）：
- 分享码（`AIF`+6 位）+ 推荐奖励（推荐人 +30 天）。
- 会员权益（档位 + 额度）。
- 卡片（每日能量 / 桃花 / 月度）+ 报告入口。

复用邀请码/会员逻辑见 [邀请码逻辑参考.md](邀请码逻辑参考.md)。

## 二、新增：会员发布采购/招聘信息（AIF 没有，ZTEIST 新加）

会员中心里加一个「信息发布」板块：会员可发布**采购**或**招聘**信息，留存展示。

### posts 表
| 列 | 说明 |
|---|---|
| id | 主键 |
| uid | 发布者 |
| kind | `purchase`(采购) / `recruit`(招聘) |
| title | 标题 |
| content | 内容 |
| contact | 联系方式 |
| status | `active` / `closed` |
| created_at | |

### 端点（草案）
- `POST /api/post/create` —— 发布（**会员鉴权**）
- `GET /api/post/list` —— 列表（按 kind 筛选 + 分页）
- `POST /api/post/close` —— 发布者自己关闭

### 规则
- 仅会员可发布（复用会员鉴权逻辑）。
- 采购 / 招聘两类分开，列表可按 kind 过滤。
- 发布者能关闭自己的帖子（status → closed）。
