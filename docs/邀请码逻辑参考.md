# 邀请码逻辑参考（从 AI-Fortune 复用）

> 权威源码：`F:\solar-scoring\apps\web-api\src\db.ts`
> 用途：ZTEIST 会员注册复用邀请码逻辑时，照此结构在 ZTEIST 里重新实现一份（独立演进，不共享后端）。

## 一、数据表（3 张）

### invite_codes（邀请码表）
| 列 | 说明 |
|---|---|
| code | 主键，`AIF` + 6 位字母数字（去掉易混淆 I/O/0/1）|
| member_type | 会员档（beta 等）|
| duration_days | 有效天数 |
| period_quota | 周期额度 |
| owner_uid | 归属用户（`NULL` = 创始码）|
| used_by / used_at | 被谁用 / 何时（一次性码用）|
| created_at | 创建时间 |

### code_redemptions（防重复）
- 主键 `(code, uid)`：同一人同一码只兑一次。

### referral_rewards（推荐奖励）
- `referrer_uid` / `invited_uid` / `reward_days`：推荐人 +30 天。

## 二、核心函数

### generateReferralCode(db, uid)
- 幂等：已有码直接返回。
- 生成 `AIF` + 6 位随机（去掉 I/O/0/1），查重后入库（60 天 / 2 次）。
- 碰撞兜底：`uid + now` 的 sha256 前 6 位。

### redeemInviteCode(db, code, uid)
校验顺序（顺序很重要）：
1. 必须先注册（`isRegistered`），否则 `NOT_REGISTERED`。
2. 码不存在 → 若符合 `AIF[A-Z0-9]{6,}` 格式则自动恢复（旧分享码原地复活）。
3. 不能用自己的码 → `OWN_CODE`。
4. 同一人同一码防重复 → `ALREADY_USED_BY_YOU`。
5. 已通过其他码成为会员 → `ALREADY_BOUND`（防叠加）。
6. 创始人码：普通创始人码**单次有效**；`FOUNDER_CODE` **永久无限次**。
7. 成功 → `grantMembership(uid, member_type, expiresAt, quota)` + 写 `code_redemptions`。
8. 分享码（`owner_uid` 非空）不写 `used_by`（永久有效）。

### rewardOwner(db, referrerUid, invitedUid)
- 幂等（同一 `invited_uid` 只奖一次）。
- 推荐人会员时长 +30 天。

### getReferralStats / getInviteCodeInfo
- 拉新数据 / 公开查询码信息（redeem 页展示用，无需登录）。
