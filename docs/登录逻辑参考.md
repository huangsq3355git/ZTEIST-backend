## 二、三条登录线（AIF 现有）

### 1. 昵称 + 密码
- `registerNickname`：昵称唯一校验 → scrypt 哈希 → insert `accounts` → `ensureUser`。
- `loginNickname`：按 nickname 查 → `verifyPassword`（timing-safe）。
- 密码哈希：`scrypt(salt 16字节, hash 64字节)`，存 `salt:hash`。

### 2. 邮箱 + 验证码（无密码）
- `issueCode`：6 位验证码，10 分钟有效，5 次尝试，存 `auth_codes`。
- `sendAuthCode`：Resend 发邮件（无 key 只打日志）。
- `verifyCode`：校验 → `claimAccount(email → 规范 uid)`。

### 3. Google OAuth（可选）
- state 带 return_to，回调后跳回本站。

## 三、微信扫码登录（V1.1 暂缓，需企业认证 + 备案）

### 前置门槛（硬）
- 微信开放平台「网站应用」→ **需企业认证（¥300/年）+ 域名 ICP 备案**。
- 审核通过拿 `AppID` + `AppSecret`。

### 技术流程（标准 OAuth2 扫码）
1. 前端用 `AppID` 生成登录二维码。
2. 用户微信扫码 → 确认登录。
3. 微信回调你的 `redirect_uri`，带 `code`。
4. 后端用 `code + AppSecret` 换 `access_token + openid`。
5. `openid` 映射 uid：新用户注册 / 老用户绑定。
